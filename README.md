# Amazon-Brazil-E-Commerce-SQL-Analysis

This repository contains the Amazon Brazil E-Commerce SQL Data Analysis portfolio project. It features a comprehensive suite of MySQL queries designed to answer 14 distinct business questions spanning logistics, revenue generation, customer behavior, and seller performance.

Project Overview

The analysis is built on a relational database encompassing transactional data for customers, sellers, products, orders, payments, and reviews. Applying advanced querying methodologies central to Big Data Analytics, this project transforms raw e-commerce data into strategic, actionable enterprise metrics

Key Business InsightsLogistics & Satisfaction: São Paulo (SP) sellers dominate the platform, fulfilling 70.8% of all orders. The median order-to-delivery time is exactly 10 days. Delivery satisfaction varies geographically, with PR and AP states leading with average review scores of 4.24, while MA and AL trail at 3.84.  Revenue & Payments: The top five product categories are highly competitive, with health_beauty leading at R$1,258,681 in total revenue. Credit cards are the dominant payment method, capturing 75% of total order volume and generating the highest average order value at R$163.94.  Platform Health: The catalogue and seller ecosystems are highly active, revealing zero dormant sellers and zero never-ordered products. Additionally, 590 sellers have fulfilled more orders than the platform average.  Technical ExecutionAll queries in this repository were written and optimized using MySQL. The code utilizes structured database design principles, incorporating complex joins, subqueries, and window functions to aggregate large-scale transactional data efficiently.
